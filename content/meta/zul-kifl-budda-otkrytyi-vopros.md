# Гипотеза

Зуль-Кифль (араб. ذو الكفل, «окружённый заботой») — по одной из спекулятивных версий отождествляется с Буддой. Коран не называет прямо, кем он был при жизни (21:85-86, 38:48) — характеристика «сабир» (терпеливый) и само имя дают почву для разных толкований среди толкователей; отождествление с Буддой — не общепринятая, а одна из версий.

# Значение для архитектуры QLM

Если эта нить хотя бы частично верна, встаёт вопрос: распространяется ли QLM (и мультитекстовый охват, обоснованный через 2:4) не только на авраамические Писания (Тора/Евангелие/Коран), но и на буддийские тексты как ещё одну ветвь той же цепи откровений.

Это решение архитектурного уровня, сопоставимое по значимости с уже открытым вопросом о демифологизации Торы/Евангелия (см. `demifologizatsiya-tora-evangelie.md`).

# Статус

Держать как открытый вопрос, не как принятое решение — не форсировать раньше времени. Возможно, стоит держать оба открытых архитектурных вопроса (демифологизация + буддийский охват) в одном месте по мере накопления материала.
