# Назначение

Существующий шаблон (`QCL_Script_Template.md`) фиксирует один случай скрипта — сюжет, эго-отклик, истинный отклик. Но скрипт срабатывает многократно на разном материале (см. `otkhod-ot-tsentra` — уже минимум 4 проявления: corpus.wikiquran.info, ноутбук, мотик, отговорка про платформу). Нужен слой, который показывает не отдельный случай, а **траекторию** — как со временем скриптовое проживание сюжета замещается духовным.

**Терминология:** проживание, не проигрывание. Проживание сюжета по скрипту (эго) и проживание сюжета по методологии (душа) — жизнь каждого пророка есть методология проживания. Опора: **33:21** — «в посланнике Аллаха вам явлен прекрасный образец проживания» (wikiquran переводит «усватун хасана» именно как «образец проживания», а не абстрактный пример) — жизнь как таковая, не только текст, может быть образцом проживания методологии.

# Добавляемый раздел (вставлять в конец файла скрипт-профиля, после «Заметки»)

```markdown
---

# Проживания

<!-- Каждое новое срабатывание этого же скрипта — новая строка.
Тип отклика: скрипт (эго победил) / переходный (замечен, но не полностью перехвачен) / духовный (истинный отклик реализован).
Цель — видеть тренд по времени, а не оценивать отдельный случай. -->

| Дата | Событие (ссылка) | Тип отклика | Заметка |
|------|-------------------|-------------|---------|
|      |                   |             |         |
```

# Пример заполнения — на паттерне `otkhod-ot-tsentra`

| Дата | Событие | Тип отклика | Заметка |
|------|---------|-------------|---------|
| ~2026-06 | corpus.wikiquran.info — отход от изучения | скрипт | постфактум, осознано задним числом |
| 2026-07-01 | `motik-i-shchedrost.md` — «сначала квартира, потом проекты» | скрипт | тоже постфактум, но уже сформулирован как явный паттерн |
| 2026-07 | «ноутбук как табельное оружие» | переходный | скрипт пойман, но отклик не полностью духовный |
| 2026-07-20 | `otkladyvanie-zagruzki-qcl.md` — отговорка про многопользовательскую платформу | переходный | скрипт пойман **в моменте**, а не постфактум — рост в стадии перехвата; истинный отклик сформулирован и применён (события загружены в тот же день) |

Видимый тренд: от «постфактум + скрипт полностью реализован» к «в моменте + скрипт перехвачен до полной реализации». Это и есть измеримая духовная прогрессия для одного конкретного паттерна — постепенная замена скриптового проживания сюжета на духовное.

# Опора на множественность притч

**39:27-28** — «Мы определенно привели в этом Коране для Людей, всевозможные притчи, — возможно они (воспользуются) методологией». Множественность притч в Писании — не избыточность, а сама методология: разные сюжеты для разных ситуаций проживания. Раздел «Проживания» — практическое приложение того же принципа к одному конкретному скрипту: не одна фиксация, а множество случаев, сверяемых с методологией.

# Применение

При загрузке нового события с уже известным `script:` — не создавать новый скрипт-профиль, а добавлять строку в «Проживания» существующего. Новый профиль создаётся только когда паттерн действительно новый.
